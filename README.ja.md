# 無限の猿定理シミュレータ

1 秒に 1 文字、ランダムなひらがなを生成して、太宰治『走れメロス』の全文と一致する日を待ち続けるサイトです。

[imt.lapius7.com](https://imt.lapius7.com) のソースコードです。参考のために公開していて、自分で動かすことは想定していません。

## 何をするか

- サーバーが 1 か所で、1 秒に 1 文字ずつ、清音ひらがな 46 字(ん・を を含む)から一様に選んで生成します。閲覧者がいない間も止まりません。
- 生成列が目標文の先頭から連続して一致している長さを追います。不一致のときは KMP の失敗関数に従って戻します。
- 全文が一致したら生成を止め、完了日時を記録してサイトに表示します。
- 画面では、生成中の文字の流れ、累計文字数、稼働日数、現在の一致の長さ、これまでの最長一致、全文一致の確率の見積もり、目標文(一致した部分を強調)、最近の生成文字をリアルタイムで見られます。配信には Server-Sent Events を使い、切れたときは自動で再接続して最新の状態に追いつきます。
- 累計・一致の状態・最長一致は MySQL に保存します。再起動しても引き継ぎ、止まっていた間の分は数えません。生成した文字そのものは、直近 86,400 文字(1 日分)だけを残し、古いものから削除します。

## 目標文

目標文は 清音ひらがな **10,685 文字** です。`scripts/build-target.ts`(`bun run target`)で、次の手順を最初からやり直せます。

1. [青空文庫の『走れメロス』](https://www.aozora.gr.jp/cards/000035/files/1567_14913.html)を取得し、本文だけを取り出します。ヘッダ、フッタ、底本情報、`［＃…］` の注記は除きます。
2. ルビ(88 件)は、ルビの読みで置き換えます。
3. ルビの無い漢字は、形態素解析(kuromoji)の読みで補います。読みが得られない語(此・警吏・刑吏・お互い・裂目など)と、数詞の読み違い(一人・二人・三人・三里)は、スクリプト内の補正表で直しています。
4. ひらがなとカタカナ以外(句読点・記号・長音「ー」・空白・英数)を除き、カタカナはひらがなにします。
5. 濁点・半濁点・小書き文字を清音にします(が→か、ぱ→は、っ→つ、ゃ→や、ゔ→う)。清音 46 字に収まらない文字があれば、スクリプトはエラーで止まります。

> [!NOTE]
> 漢字の読みは機械が決めたもので、全文を人が校正してはいません。読みの誤りがありうるので、使った読みは `data/target.readings.tsv` に一覧で残しています。

生成する文字も同じ 46 字なので、生成列と目標文は同じ文字集合で比べられます。

## 全文一致の確率

1 文字が一致する確率は 1/46 です。連続 10,685 文字が目標文と一致する確率は 46 の -10,685 乗(約 10 の -17,766 乗)で、期待される所要時間は約 10 の 17,759 乗年です。宇宙の年齢の約 10 の 17,748 乗倍にあたります。サイトには、そのときの累計文字数から求めた「ここまでに全文一致している確率」も表示します。
